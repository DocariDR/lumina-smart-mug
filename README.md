# Product Landing Page

![Status](https://img.shields.io/badge/status-termin%C3%A9-brightgreen)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)

![Flexbox](https://img.shields.io/badge/Flexbox-layout-blue)

Page d'atterrissage d'un produit fictif (une tasse connectée), avec formulaire d'inscription, fonctionnalités, vidéo et tarif.

![Aperçu du projet](screenshot.png)

## Ce que j'ai mis en pratique

- Mise en page avec Flexbox : header, formulaire d'inscription, grille de fonctionnalités et centrage des blocs.
- Variable CSS (`--brand-color`) pour centraliser la couleur de marque, choisie pour respecter un contraste suffisant.
- Design responsive avec une media query (`max-width: 600px`) qui passe les blocs en colonne.
- Intégration d'une vidéo YouTube avec `<iframe>`.

- CSS3 (Flexbox, variables CSS, media queries)

## Installation locale

```bash
git clone https://github.com/DocariDR/product-landing-page-freecodecamp.git
cd product-landing-page-freecodecamp
```

Puis ouvre `index.html` dans ton navigateur, aucune dépendance à installer.
